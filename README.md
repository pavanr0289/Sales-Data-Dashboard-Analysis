 📊 Super Store Sales Dashboard Analysis

An interactive sales data analysis dashboard created using Power BI.

📌 Project Overview

This project focuses on analyzing Super Store sales data using an interactive Power BI dashboard. The dashboard provides valuable insights into sales, profit, customer segments, payment modes, shipping modes, categories, and sub-categories.

 🛠️ Tools Used

- Power BI
- Data Analysis
- Data Visualization
- Excel / CSV

 📊 Key Performance Indicators

- Total Sales: 522K
- Total Profit: 68K

 📈 Dashboard Analysis

The dashboard includes the following insights:

- Sales and profit analysis by month and year
- Sales analysis by customer segment
- Sales analysis by payment mode
- Sales by shipping mode
- Sales by sub-category
- Sales by product category
- Regional sales analysis

🎯 Key Insights

- Consumer segment contributes the highest percentage of sales.
- Standard Class is the most commonly used shipping mode.
- The dashboard allows users to analyze sales across different regions.
- Technology and Furniture categories generate significant sales.
